# Anki 本地记忆主页（Anki Visualizer）

极简纯白风格（严格控制在黑白灰、Anki 蓝、打卡绿 3 色以内）的本地 Anki 数据可视化前端看板。无需上传云端，100% 本地隐私安全。

---

## 核心聚焦模块

1. **今日状态（Today）**
   - 一眼查看今日是否已打卡、今日已复习卡片数、学习用时与剩余待复习量。
2. **坚持了多久（Streak）**
   - 突出展示当前连续打卡天数、累计坚持天数、历史最长连胜纪录与历史总复习量。
3. **累计卡片资产（Cards Asset）**
   - 呈现当前活跃卡片数、历史总沉淀卡片规模以及熟练卡（Mature）/ 巩固期（Young）/ 学习中（Learn）/ 新卡（New）的记忆成熟阶梯。
4. **经典 Anki 牌组总览（Decks）**
   - 还原 Anki 首页熟悉的牌组层级列表，清晰展示各牌组的新卡（New）、学习中（Learn）、待复习（Due）与总卡数，点击任意牌组即可联动筛选下方卡片。
5. **坚持打卡热力图（Review Heatmap）**
   - 全年日历打卡矩阵，支持按年份切换查看每一天的复习强度与学习时长。
6. **已累计卡片浏览与复习（Card Explorer）**
   - 支持按关键词、牌组、记忆状态筛选卡片，点击即可翻看答案，并结合 24 小时学习时段与四键认知反馈辅助复盘。

## 启动与使用方式

### 方式一：一键启动本地服务（推荐）
双击目录下的 `start.bat`（或运行 `python server.py`），自动打开 `http://127.0.0.1:8090`（默认使用 `8090` 端口，与 AnkiConnect 的 `8765` 端口互不冲突）。

在 Anki 中背完卡片后，点击页面右上角 **「一键同步最新」** 即可实时刷新数据。

### 方式二：浏览器直接拖拽导入
直接双击 `index.html` 在浏览器中打开，将本地 Anki 数据库 `collection.anki2`（Windows 默认路径通常为 `%APPDATA%\Anki2\<你的账户名>\collection.anki2`）或导出的 JSON 文件拖入页面，内置 WebAssembly SQLite（`sql.js`）引擎会在浏览器本地直接解析。

### 方式三：手动导出数据
```bash
python export_data.py
```
会自动定位本地 Anki 数据库并生成 `anki_data.json` 与 `data.js`（均已加入 `.gitignore`，不会提交个人学习数据到仓库）。
